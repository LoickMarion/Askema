# Askema

Askema is a desktop app that generates printable math worksheets as PDFs. Pick topics, choose how many questions and what difficulty, preview the page live, and export a ready-to-print worksheet with an answer key.

**[Download the latest release](https://github.com/LoickMarion/Askema/releases/latest)** · Website: https://askemamath.com

## Install

| Platform | File | Notes |
| --- | --- | --- |
| Windows | `Askema-<version>.msi` | Run the installer. |
| Ubuntu / Debian | `askema_<version>_amd64.deb` | `sudo apt install ./askema_<version>_amd64.deb`. Built on Ubuntu 24.04, so it needs a similarly recent system. |
| macOS | Coming soon | |

Askema works offline and bundles everything it needs to produce PDFs. It collects no data and never contacts a server.
